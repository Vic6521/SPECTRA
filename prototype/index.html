三大会背景与统计口径。热词不是真理，是可复现的压缩。

CVPR

IEEE/CVF 计算机视觉与模式识别会议，每年举办，体量最大。作业引用 2025 投稿 13008、录取 2878。

ICCV

国际计算机视觉大会，通常与 ECCV 交替的奇数年。偏重视觉基础问题与新范式。

ECCV

欧洲计算机视觉国际会议，偶数年。与 CVPR/ICCV 共同构成 CV 三大会。

热度口径

语料来自标题、作者关键词与摘要（摘要降权）。停用词过滤后：

heat(k, y) = freq(k, y) × (1 + 0.5 × growth(k, y))

growth 为近两年（2025–2026）相对此前年份的增长率，截断到 [-1, 3]。数据窗口 2022–2026。数据源：DBLP 公开 API / 会议公开列表 / 课程数据集。爬取仅用于教学。
